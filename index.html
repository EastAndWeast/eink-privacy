中文

「墨水屏阅读助手」是一个纯本地运行的浏览器扩展：它把网页配色转换为电子纸观感。

  • 我们不收集任何数据。不收集浏览历史、页面内容、个人信息、使用统计，无任何形式的遥测或分析。
  • 不发出任何网络请求。扩展的全部资源（脚本、样式、图标）随安装包分发，运行时不连接任何服务器。
  • 所有配置仅保存在你的浏览器本地（chrome.storage.local），不会上传。你可随时在设置页导出为 JSON 文件，卸载扩展即全部删除。
  • 权限用途：storage（本地保存配置）；scripting/activeTab 与 http/https 主机访问（在你开启阅读模式后，对你正在浏览的普通网页应用配色转换）。扩展默认关闭，不访问、不上传任何页面内容。

English

E-Ink Reading Assistant is a fully local browser extension that restyles web pages into an e-ink paper look.

  • We collect no data. No browsing history, page content, personal information, or usage statistics. No telemetry or analytics of any kind.
  • No network requests. All assets ship with the package; the extension never connects to any server at runtime.
  • All settings stay in your browser's local storage (chrome.storage.local). Export them anytime as JSON from the options page; uninstalling removes everything.
  • Permissions: storage (save your presets/site rules locally); scripting/activeTab and http/https host access (apply the color transform to regular pages you browse, only while reading mode is on). The extension is off by default and never reads or uploads page content.
